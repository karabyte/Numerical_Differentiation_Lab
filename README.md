# Numerical_Differentiation_Lab

A hands-on study of numerical differentiation using finite difference methods and Taylor series.

## Source

This project follows the numerical differentiation lecture by Steve Brunton, focusing on finite difference approximations and their connection to Taylor series.

## Topics Covered

* Forward Difference
* Backward Difference
* Central Difference
* Taylor Series and truncation error
* Step-size selection
* Numerical error and accuracy
* Comparison with the exact derivative

## Implementation

Using the function

[
f(t)=\sin(t)
]

the exact derivative

[
f'(t)=\cos(t)
]

was used as the reference solution.

Forward, backward, and central difference methods were implemented from scratch and tested with different step sizes.

The numerical results were compared with the analytical derivative, and the error behavior was visualized using plots.

## Tools

* Python
* NumPy
* Matplotlib
* Google Colab

## Goal

The main goal of this laboratory was to understand how continuous mathematical derivatives can be approximated computationally and how step size affects numerical accuracy.
